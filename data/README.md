## Robustness of Graph Neural Networks

This repository contains code for evaluating the robustness of GNN models
(GCN, GAT, GraphSAGE) under structural perturbations.

### Folder Structure
- `code/` – Model, training, perturbation logic
- `data/` – Datasets (auto-downloaded)
- `results/` – CSV and plots
- `paper/` – LaTeX paper

### Run
```bash
python code/main.py
